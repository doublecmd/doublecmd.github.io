1. Packer-Plugins (WCX)


Base64

Das Base64-Plugin ermöglicht das Kodieren und Dekodieren von Dateien nach dem Verfahren Base64. Das ist einer der Standards, um Binärdaten mit druckbaren ASCII-Zeichen zu kodieren.


CPIO

Packer-Plugin zum Entpacken von CPIO-Archiven.


DEB

Packer-Plugin zum Entpacken der Paketdateien des Paketverwaltungssystems dpkg (Debian und darauf aufbauende Distributionen).

Linux und andere Unix-ähnliche Betriebssysteme (unter Windows verwendet Double Commander für dieses Format das Plugin SevenZip).


RPM

Packer-Plugin zum Entpacken der Paketdateien des Paketverwaltungssystems von Red Hat (Red Hat Linux, SUSE Linux und weitere).


SevenZip

Packer-Plugin für die Arbeit mit Dateien der Typen .7z, .arj, .cab, .cpio, .cramfs, .deb, .dmg, .fat, .hfs, .iso, .lha, .lzh, .ntfs, .squashfs, .taz, .vhd, .wim, .xar und .z. Wir können auch weitere Dateitypen hinzufügen, die von 7-Zip unterstützt werden.

Hinweis: Einige Formate sind schreibgeschützt, das heißt, es stehen nur das Anzeigen des Inhalts, das Entpacken und das Prüfen zur Verfügung.

Nur Windows und Linux.


UnRAR

Packer-Plugin zum Entpacken von RAR-Archiven.

Für die Verwendung dieses Plugins benötigen wir die Bibliothek UnRAR. Das Plugin verwendet unrar.dll (Windows), libunrar.dylib (macOS), libunrar.so oder libunrar.so.5 (Linux und andere Unix-ähnliche Betriebssysteme).

Die Distributionen von Double Commander für Windows und die portablen Versionen für Linux enthalten die nötige Bibliothek. In anderen Fällen können wir die üblichen Wege nutzen, um Bibliotheken im Betriebssystem zu beziehen (zum Beispiel das Paket libunrar5 in Debian/Ubuntu oder libunrar in Arch Linux). Andernfalls können wir versuchen, auf dieser Seite eine passende Variante zu finden (die Datei muss in das Systemverzeichnis oder in das Verzeichnis kopiert werden, in dem die Programmdatei von Double Commander liegt).

Das Plugin unterstützt außerdem das Packen von Dateien in ein RAR-Archiv. Dafür müssen wir in den Plugin-Einstellungen den Pfad zu WinRAR.exe (nur Windows) oder zum Kommandozeilenprogramm rar angeben.


Zip

Packer-Plugin für die Arbeit mit Archiven der Typen .bz2, .gz, .jar, .lzma, .tar, .tbz, .tgz, .tlz, .txz, .tzst, .xz, .zip, .zipx und .zst. Dieses Plugin kann außerdem Dateien öffnen, die auf ZIP beruhen (EPUB, Office Open XML, OpenDocument-Format, CRX, XPI und weitere).

Benötigt zusätzliche Kompressor-Bibliotheken:

  • Brotli (nur Dekomprimieren): libbrotlidec.dll (Windows), libbrotlidec.dylib (macOS), libbrotlidec.so.1 (Linux und andere Unix-ähnliche Betriebssysteme).

  • bzip2: bz2.dll (Windows), libbz2.dylib (macOS), libbz2.so.1 (Linux und andere Unix-ähnliche Betriebssysteme).

  • XZ: liblzma.dll (Windows), liblzma.dylib (macOS), liblzma.so.5 (Linux und andere Unix-ähnliche Betriebssysteme).

  • Zstandard: libzstd.dll (Windows), libzstd.dylib (macOS), libzstd.so.1 (Linux und andere Unix-ähnliche Betriebssysteme).

Die Distributionen von Double Commander für Windows enthalten alle nötigen Bibliotheken, und unter Linux sind diese Bibliotheken auf Desktop-Systemen und Arbeitsplatzrechnern üblicherweise standardmäßig installiert.

2. Inhalts-Plugins (WDX)


Eingebautes Exif-Plugin

Das Programm enthält ein eingebautes Exif-Inhalts-Plugin, um einige Daten zu lesen, die in den Metadaten von JPEG-Dateien gespeichert sein können: Datum, Abmessungen in Pixeln, Bildausrichtung und Kamerainformationen.

Nur JPEG-Bilder.


AudioInfo

Dieses Inhalts-Plugin zeigt Informationen zu Audiodateien, technische Angaben (Dauer, Bitrate, Anzahl der Kanäle und so weiter) und Metadaten (Titel, Interpret und weitere).

Die folgenden Arten von Metadaten werden unterstützt: ID3v1 (1.0, 1.1), ID3v2 (2.2, 2.3, 2.4), APE (1.0, 2.0), Vorbis-Kommentar.


DEB

Dieses Inhalts-Plugin zeigt Informationen zu den Paketdateien des Paketverwaltungssystems dpkg (Debian und darauf aufbauende Distributionen): Paketname, Version, Beschreibung, Abhängigkeiten und weitere.


RPM

Dieses Inhalts-Plugin zeigt Informationen zu den Paketdateien des Paketverwaltungssystems von Red Hat (Red Hat Linux, SUSE Linux und weitere): Paketname, Version, Beschreibung und weitere.


Lua-Skripte

Das Verzeichnis plugins/wdx/scripts enthält mehrere Beispiele für Inhalts-Plugins, die in Lua geschrieben sind (Einzelheiten stehen auf der Hilfeseite Lua-Skripte).

Diese Plugins sind den Programmeinstellungen nicht hinzugefügt.

  • descriptionwdx.lua – liest Dateibeschreibungen aus descript.ion.

  • fulltextodtwdx.lua – sucht Text in OpenDocument-Text-Dateien (ODT). Benötigt odt2txt.

  • simplewdx.lua – einfaches Beispiel mit mehreren Feldern.

  • textlinewdx.lua – gibt die ersten Zeilen von reinen Textdateien (.txt, .ini) nacheinander zurück, von der ersten bis zur fünften.

3. Dateisystem-Plugins (WFX)


FTP

Dies ist ein Dateisystem-Plugin für die Arbeit mit den folgenden Netzwerkprotokollen: FTP, FTPS, FTPES, SFTP und SSH+SCP. Das Plugin unterstützt außerdem die Arbeit mit Proxy-Servern (HTTP, SOCKS 4 oder SOCKS 5).

Benötigt zusätzliche Bibliotheken:

1) Protokolle SSL und TLS

Die kryptografische Bibliothek OpenSSL (3.1, 3.0, 1.1.1, 1.1.0, 1.0.2, 1.0.1):

  • Windows: Das Plugin enthält eine Liste gebräuchlicher Namen, und die benötigten Dateien werden automatisch gefunden.
  • macOS: libssl.N.dylib und libcrypto.N.dylib (wobei „N“ eine Versionsnummer ist) oder libssl.dylib und libcrypto.dylib.
  • Linux und andere Unix-ähnliche Betriebssysteme: libssl.so.N und libcrypto.so.N, wobei „N“ eine Versionsnummer ist.

Übersetzte OpenSSL-Binärdateien für Windows sind hier zu finden. In anderen Fällen können wir die Paketverwaltung des Betriebssystems verwenden (zum Beispiel das Paket libssl3 oder libssl1.1 in Debian/Ubuntu, openssl in Arch Linux, openssl unter macOS (Homebrew)).

Hinweis: Unter Windows müssen die Bibliotheken neben der Programmdatei von Double Commander oder im Windows-Systemverzeichnis liegen.

Alternativ kann das Plugin unter Linux die Bibliothek GnuTLS verwenden (libgnutls.so.N, wobei „N“ eine Versionsnummer ist).

2) Protokoll SSH

Die Bibliothek libssh: Das FTP-Plugin verwendet libssh2.dll (Windows), libssh2.dylib (macOS) oder libssh2.so.1 (Linux und andere Unix-ähnliche Betriebssysteme).

Die Distributionen von Double Commander für Windows enthalten diese Bibliothek. In anderen Fällen können wir die üblichen Wege nutzen, um Bibliotheken im Betriebssystem zu beziehen (zum Beispiel das Paket libssh2-1 in Debian/Ubuntu, libssh2 in Arch Linux, libssh2 unter macOS (Homebrew)).

Das Plugin ermöglicht die Verwendung eines SSH-Authentifizierungsagenten (zum Beispiel ssh-agent aus der Programmsammlung OpenSSH, Pageant von PuTTY).


MacCloud

Offizielles Cloud-Plugin für macOS, es unterstützt:

  • DropBox
  • Yandex
  • One Drive
  • Box
  • Amazon S3
  • BackBlaze B2
  • Alibaba Cloud OSS
  • Tencent Cloud COS
  • Huawei Cloud OBS
  • Qiniu KODO
  • Upyun USS
  • S3 Compatible

Nur macOS.

4. Lister-Plugins (WLX)


MacPreview

Universelles Plugin (Office-Dokumentformate, Bilder, Video- und Audiodateien und mehr) auf Basis von Quick Look, wie im Finder.

Nur macOS.


Explorer Preview

Plugin für die Anzeige einer umfangreichen Vorschau. Die Schnittstelle IPreviewHandler unterstützt viele Formate (abhängig von der Version des Betriebssystems und den installierten Anwendungen). Standardmäßig sind nur HTML-Dateien zur Erkennungszeichenkette hinzugefügt.

Hinweis: Vorschau-Handler zeigen möglicherweise nicht alle in der Datei enthaltenen Informationen an.

Nur Windows.


Rich Text Format

Plugin zum Anzeigen von RTF-Dateien.

Nur Windows.


WlxMplayer

Plugin zum Anzeigen von Videodateien. Benötigt mplayer.

Nur Linux.


Windows Media Player

Plugin zum Wiedergeben von Audio- und Videodateien. Dieses Plugin verwendet die Schnittstelle IWMPPlayer4 (ActiveX) und benötigt Windows Media Player 9 oder neuer.

Nur Windows.

(nach oben)

5. Such-Plugin (DSX)


DSXLocate

Dieses Plugin verwendet locate und dessen Dateidatenbank für die Suche. Wir können nach dem Dateinamen, einem Teil davon oder nach einer Maske suchen (das Zeichen „*“ steht für eine beliebige Anzahl von Zeichen).

Linux und andere Unix-ähnliche Betriebssysteme.
